《这一年，我在伦敦干了些什么？》交互网页雏形

打开方式：双击 index.html（建议 Chrome / Safari / Edge）。
包含三张已提供素材中的两张静态照片：导师合照、爱丁堡；另包含由 MOV 转码的可播放实况视频。

如何补图：
1. 在 assets 文件夹放入新照片，如 commute.jpg、coffee.jpg、desk.jpg。
2. 用文本编辑器打开 index.html，找到 `const ASSETS={...}` 那一行。
3. 把对应字段由 null 修改成 'assets/文件名.jpg'，例如 commute:'assets/commute.jpg'。
4. 保存后刷新网页。更详细的剧情改写在下方 `const scenes=[...]`。

重要：页面中标注“等待照片”的地方是素材占位，不是你的真实经历；两张照片保持原样。伦敦上学路、咖啡、吃饭和旅行的具体细节仍可后续替换。暂未公开部署。网页的本地文件可离线打开；如播放出现浏览器安全限制，可用本地静态服务器打开。
